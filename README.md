# Volodya Player :) 🎵

A simple, lightweight, and beautiful web music player with MP3 file upload support and customizable visuals. Works right in your browser without any extra installations.

## ✨ Features
- 📂 Upload and play your own MP3 tracks.
- 🎨 Customizable interface visuals.
- 🚀 Runs locally in any modern browser.

## 🛠️ Technologies
- HTML5 / CSS3
- JavaScript

## 🚀 How to Run
1. Download the repository or open the `index.html` file in your browser.
2. Drop in your favorite track and enjoy the music! ^_^
